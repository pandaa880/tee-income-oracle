## Claude Code

- Explore with codegraph first (AGENTS.md → "Exploring the code: codegraph"): run
  `codegraph explore`, `codegraph context` or `codegraph node` before a broad grep or an
  Explore subagent, and tell any subagent you spawn to do the same.
- In a fresh worktree, run `codegraph init` there; the index in the main checkout
  doesn't follow you.

# Independent JWS Cross-Check

This directory contains an independent cross-check harness for the `tio-core` JWS implementation.

## What it proves
1. Node -> Rust: Rust correctly verifies valid RS256/RS512 detached and compact signatures generated by Node.js (`node:crypto`), and correctly rejects tampered signatures, swapped headers (alg confusion), and unknown kids.
2. Rust -> Node: Node correctly verifies valid detached signatures generated by Rust's `FiuSigningKey`.
3. Wycheproof: Rust correctly passes all C2SP Wycheproof RSA PKCS#1 v1.5 test cases for 2048-bit keys (SHA-256 and SHA-512), verifying valid/acceptable signatures and rejecting invalid ones or malformed keys.

## Keys
**ALL KEYS ARE FOR TEST ONLY**.
The Node tests use the public RFC 7515 Appendix A.2 key and RFC 7520 Section 3.4 key. Do not pin these in a deployed enclave!

## How to run
```sh
bash run.sh
```
